# Third-party components

- **Arduino core for ESP32** (Espressif) - LGPL-2.1 and others, used as the Arduino framework.
- **GFX Library for Arduino (Arduino_GFX)** by moononournation - the copy bundled in Waveshare's repo
  (waveshareteam/ESP32-S3-Touch-AMOLED-2.06, an Apache-2.0 repository) is used for the CO5300 display driver.
  Check and keep the upstream license notice when distributing binaries.
- Pin numbers: from Waveshare's official `pin_config.h` (Apache-2.0).

Not used on purpose: Waveshare `Arduino_DriveBus` (GPL-3.0).
